# Visor de Markdown Paginado

## Descripción
`mdview_pager.py` es un visor de Markdown paginado diseñado para usar dentro de una sesión de `screen`. Permite navegar por archivos Markdown utilizando teclas de flecha, página siguiente/antigua y otros comandos.

## Requisitos
- Python 3.6 o superior
- La librería `rich` instalada
